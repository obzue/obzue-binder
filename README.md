# Obzue Binder

Company desk for ObzueAI. Remake of the Paperclip *procedure* (heartbeat, board, roles), not a fork of [paperclipai/paperclip](https://github.com/paperclipai/paperclip).

Not Corta. Not a sentient company. Idle with an empty board is success.

## Install in Grok

Copy `skills/obzue-binder` to `/home/workdir/.grok/skills/obzue-binder`.

## Wake

```bash
python3 skills/obzue-binder/scripts/check_board.py board.json
python3 skills/obzue-binder/scripts/wake.py board.json
```
